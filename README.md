# Pantry Pilot

## Run locally

```bash
npm install
npm run dev
```

## Install on a phone

Deploy the repository with the included GitHub Actions workflow (Settings → Pages → Source: **GitHub Actions**). Open the HTTPS Pages URL on your phone. On Android Chrome, choose **Install app**; on iPhone Safari, choose **Share → Add to Home Screen**. The app works offline after its first visit.

## Backups

Settings includes JSON export and import. Imports merge lists by name and preserve existing saved lists rather than overwriting them.
